## 启动

双击 **`启动 VibeNotes.bat`** 即可（无需安装任何东西，Electron 运行时已内置在 `runtime/` 文件夹）。
启动后程序只驻留屏幕顶部 + 系统托盘，不占任务栏。

> 整个 `VibeNotes.win` 文件夹即绿色便携版：拷贝到任意 Windows 10/11 x64 机器解压即用。
> 启动器已内置两条兼容性处理：清空 `ELECTRON_RUN_AS_NODE` 环境变量（防止在 Electron 宿主终端里启动时退化为 Node 模式）、
> `--disable-gpu --no-sandbox`（规避 GPU 驱动异常与受限宿主的沙箱崩溃；本应用只加载本地文件，软件渲染流畅）。

## 功能

| 功能 | 说明 |
|---|---|
| 顶部触发 | 悬停 / 点击 / 仅托盘 三种模式（悬停模式下进入顶部热区约 0.3s 后展开） |
| 挂件拖拽移位 | 在顶部小挂件上**按住拖动**即可自由移动窗口：X 轴**任意位置**（无对齐档位）、支持 Y 轴与**跨屏拖到第二显示器**（范围覆盖整个虚拟桌面）；拖到显示器顶部附近（~48px）时吸附该屏顶边（X 保持自由），其他位置松手即原地放置；位置会被记住（含所在显示器），重启后恢复 |
| 面板拖拽把手 | 展开面板工具栏最左侧的 ⠿ 把手：按住拖动即可移动整个面板（展开、固定状态均可），X/Y 自由放置并记住位置；拖动过程中不会触发自动收起 |
| 固定（📌） | 展开面板工具栏的固定按钮：点击后**面板常驻展开且始终置顶**（悬停移出、点击外部、窗口失焦均不再自动收起）；固定状态下仍可用 ⠿ 把手拖动面板到任意位置；再次点击取消。用 Esc / Ctrl+W / 托盘显式收起会自动解除固定；固定状态重启后保持 |
| 盒子快捷收起 | 设置里二选一：**鼠标移出**（离开面板 ~0.5s 自动收起）/ **无**（仅 Esc、Ctrl+W、托盘、关闭按钮收起）。原"窗口失焦"选项因多屏与焦点场景下行为不稳定已移除 |
| 多标签 Markdown 便签 | 新建（Ctrl+T）、删除、恢复上次删除、标题取首行（42 字截断）、每标签独立光标位置 |
| 编辑态语法着色 | 标题 / 粗斜体 / 删除线 / 行内代码 / 代码块 / 引用 / 列表 / 任务清单 / 链接 实时着色 |
| 预览（Ctrl+P） | 迷你 Markdown 渲染，本地图片可直接显示，链接可点击打开 |
| 粘贴截图 | 编辑器内 Ctrl+V 粘贴图片 → 自动存到数据目录 `images/` 并插入引用 |
| 文件暂存区 | 拖入文件即暂存（仅保留引用，不移动原文件，上限 100 个、自动去重）；单击打开、右键在文件夹中显示、**拖出到资源管理器 / 浏览器上传区**；原文件被删会标记"已不存在" |
| 保持唤醒 | 防止系统休眠；另有"屏幕常亮"独立开关（对应原版 pmset/caffeinate 方案，Windows 用 powerSaveBlocker 实现，无需管理员） |
| 托盘 | 左键点击展开/收起；右键菜单：触发模式、防休眠、屏幕常亮、开机自启、打开数据文件夹、退出 |
| 收起方式 | Esc / Ctrl+W / 托盘 / 再点顶部小挂件；悬停模式鼠标移开自动收起；📌 固定状态下仅显式操作可收起 |

## 数据保存

全部保存在本机 `%APPDATA%\VibeNotes\`（旧版 NotchNotes 的数据会在新版首次启动时自动迁移过来）：

- `notes.json` —— 便签（防抖 180ms 自动保存，与原版一致）
- `shelf.json` —— 文件暂存记录
- `settings.json` —— 触发模式、防休眠等设置
- `images/` —— 便签中粘贴的图片

覆盖升级/重装本程序不影响这些数据。

## 目录结构

```
VibeNotes.win/                 ← 绿色便携版，可直接分享
├── 启动 VibeNotes.bat          ← 双击启动
├── package.json
├── README.md
├── app/                        ← 应用源码
│   ├── main.js                 ← 主进程：窗口/托盘/防休眠/持久化
│   ├── preload.js              ← 安全桥接（contextIsolation）
│   ├── index.html / style.css / app.js
│   └── assets/
│       ├── icon.png            ← 托盘图标
│       └── gen-icon.js         ← 图标生成脚本（node gen-icon.js 可重新生成）
└── runtime/                    ← Electron 33 运行时（electron.exe 及依赖，自包含）
```

**给开发者**：本目录无 node_modules，改代码后可直接用 `runtime\electron.exe .` 运行；
若需要完整 npm 开发环境（electron CLI、package-lock 等），见旁边的 `VibeNotes.dev/` 归档，
或在此目录执行 `npm install` 重建后用 `npm start` 运行。
